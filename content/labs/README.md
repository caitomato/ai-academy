# AI 学院实操材料

所有人物、公告和学习记录均为虚构。下载需要的文件，放在自己新建的空练习目录中。
课程内链接可逐个下载，不要求登录、付费、提交 API Key 或安装 Claude Code。

- notes.md：文件读取、学习卡片与技能复用。
- study.md：Markdown 源文件与预览比较。
- study-card/SKILL.md：原创技能说明样例。先作为普通任务阅读；可选安装路径按已有宿主的当前文档核对。
- slides-source.md：课件转换与长内容拆页练习。
- learning.csv：数据去重、缺失与计算口径。
- announcements.html / announcements.csv：只读浏览器采集、来源核对与四阶段工作流。
- course.md / update.md：带生效日期的知识库问答。
- state.example.json：工作流状态的教学示例，不会自动执行。
- storyboard.md：原创纸船短片制作与交付表。

验收时记录实际完成的文件、路径与检查结果。只完成纸面方案时标明“方案已完成，工具执行未验证”。
原素材、第三方视频截图与讲师头像不包含在本练习包中。
